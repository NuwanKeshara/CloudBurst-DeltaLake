# CloudBurst-DeltaLake

This project focuses on building a data pipeline to ingest and process IoT weather data and store the data in an Azure Databricks data lakehouse using Delta Lake and the Medallion Architecture. Power BI will be used to visualize the data for analysis.

![alt text](https://github.com/NuwanKeshara/CloudBurst-DeltaLake/blob/main/report/Architecture.drawio.png?raw=true)


## Tech Stack

- Cloud: Azure
- Data Ingestion: Raspberry Pi, Python
- Azure Cloud Services: Azure IoT Hub, Azure Event Hub
- Data Processing: Azure Databricks, Spark(PySpark)
- Data Visualizations: Power BI
